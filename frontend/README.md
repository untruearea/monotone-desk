# MonotoneDesk frontend

Run `pnpm install --frozen-lockfile`, `pnpm test`, `pnpm build`, then `pnpm dev`. Static output is `dist/`. The app has no configured deployment or source URL. Parent README documents the distinct domain UI, exact API, Studio61999 MetaMask provider, strict raw receipt proof and conservative tracked-hash recovery. Never substitute fixture transaction addresses for an actual deployment. Local adapter/formatter tests are not a live wallet/business-flow attestation. The SDK bundle size warning is nonfatal and retained in build evidence.
