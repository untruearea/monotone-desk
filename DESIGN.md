# MonotoneDesk design and API

Intent: inspect an explicitly synthetic, public, non-PII binned calibration sample. GenLayer validators independently fetch the exact immutable URL bytes and recompute an exact weighted least-squares monotone fit. This does not prove source truth, individual identity, out-of-sample calibration, accuracy or production model behavior.

Input: strict UTF-8 JSON object {version:1,bins:[{score,positives,count}]}; 1..16 rows; score exact integer0..10000, count exact integer1..10000, positives exact integer0..count; booleans/floats/duplicate keys/extra fields rejected; total count<=100000; raw body1..16384bytes. Duplicate scores are allowed and first aggregate by score. Scores, aggregated rows and blocks are ASCII/integer ordered.

Core: weighted PAVA with weight=count and mean=positives/count. Compare rational means by cross products; merge while left mean >= right mean, including equality, to form canonical maximal equal-rate blocks. Reduce every rational using gcd; zero=0/1. Output all aggregated bins, blocks with exact rate/count/positives/scores, per-score fitted fractions, original-input-row weighted_bin_sse=sum count*(fit-positives/count)^2 and bernoulli_sse=sum positives*(1-fit)^2+(count-positives)*fit^2. Their constant difference is documented; both minimized by the same fit. No float decisions or extrapolation. The UI may draw fractions as display numbers only.

State/API (zero constructor): open_fit(fit_id,url,sha256)->null captures strict sample into OPEN revision0; derive_fit(fit_id,expected_revision)->dict is permissionless, fresh HTTP+SHA+full PAVA, DERIVED revision1 and domain-bound cert; confirm_fit(fit_id,expected_revision,certificate_id)->null is creator-only, fresh rederive and exact record match, CONFIRMED revision2; revoke_fit(fit_id,expected_revision,reason)->null creator-only from any nonrevoked state, terminal REVOKED revision+1; get_fit(fit_id)->dict; get_configuration()->dict. Immutable input, ID never reused; history is bounded by lifecycle. Cert binds protocol/chain/address/creator/id/source URL+byte hash/revision/context/result. Stale revision, wrong owner/cert or replay fails. Failed fetch/derive leaves state unchanged; offline revocation remains possible.

Consensus: run_nondet_unsafe leader and validator each fresh fetch and derive the complete canonical packet; validator catches non-Return and any fresh-source/parser/derivation exception and returns false. All decisive numbers and all evidence bytes/bindings are compared. HTTP availability/transport and GitHub namespace provenance are assumptions; neither URL nor hash proves authorship. URL grammar explicitly captures namespace, rejects dot owner/repo/path segments, credentials/query/encoded segments/redirect assumption; no DNS/transport attestation claimed.

Frontend: source/actual deployed address configuration starts unconfigured; runtime Studio61999 MetaMask provider; open/read/derive/confirm/revoke and receipt inspector; only raw FINALIZED+bound consensus SUCCESS completes a write, with available SDK fields checked for conflicts; unknown outcome keeps submitted hash and blocks automatic retry; dictionary SDK reads only. Dedicated input table, empirical/fitted SVG plot, exact block table and both rational losses; shows chain-derived output only. Demo fixture shown locally with publicURL/deployment/hosting null.

Testing: literal 2-block fractions(1/2,11/15), original weightedSSE34/15 and BernoulliSSE163/15; same-score aggregation, equal mean merge, monotone identity, descending pool, extremes, input permutation; duplicate keys/floats/bools/unknown fields/weights/total/body/source namespace; validator forged rate/loss/binding and fresh drift; creator/CAS/wrongcert/cross-ID/replay/offline revoke; full exact SDK semantic/schema. Frontend tests cover decoded dict shape, numeric table validation and receipt failure/unknown handling; tsc/Vite build. No live deployment or browser verification.
